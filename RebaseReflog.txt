------------------------------------ Rebase --------------------------------------------

-> Git rebase is a powerful Git feature used to change the base of a branch
-> It allows you to keep the commit history cleaner and easier to understand
-> Rebase is a powerful tool in Git that allows you to move a branch to a new starting point

-> Command used to rebase
    ** git switch/checkout main (most of the time we rebase other branches to main branch)
    ** git rebase <branch_name>


-> If there are any conflicts, you will need to resolve them manually
    ** git add <resolved-files>
    ** git rebase --continue


------------------------------------ Reflog -----------------------------------------------

-> Git reflog is a command that shows you the history of your commits
    ** git reflog


-> We can find specific commit using
    ** git reflog <commit_hash>


-> If you accidentally deleted a branch or made changes that are no longer visible in the commit history, you can often recover them using the reflog
    ** git reflog <commit-hash>
    ** git reset --hard <commit-hash>
    ** git reset --hard HEAD@{1}
